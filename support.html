Support

How to use PageReel, and what to do when a page will not capture.

Getting started

  1. Install PageReel from the Chrome Web Store.
  2. Click the puzzle-piece icon in Chrome's toolbar and pin PageReel.
  3. Open the page you want, click the PageReel icon and choose Full page, Visible area or Select area.
  4. The capture opens in a new tab. Mark it up if you like, then download or copy it.

Keyboard shortcuts

ShortcutWhat it does
Alt+Shift+SOpen the PageReel menu
Alt+Shift+FCapture the full page
Alt+Shift+VCapture the visible area
Alt+Shift+ESelect an area to capture

To change them, click Change shortcuts at the bottom of the PageReel menu. If a shortcut shows a small “+” instead of keys, Chrome did not assign it, usually because another extension already uses those keys. Click the “+” to set your own.

Troubleshooting

“Chrome doesn't let extensions run on this page”

Chrome blocks every extension on its own pages: settings, the new tab page and the Chrome Web Store. PageReel works on ordinary web pages. To capture a file opened from your computer, turn on “Allow access to file URLs” in the extension's details.

“Chrome's one-time access to this tab wasn't in effect”

Chrome gives PageReel access to a tab only for the moment you click its icon. Click the icon and try again. If it keeps happening, press Allow on all sites in the message; PageReel then no longer depends on the one-time access. You can withdraw that permission at any time in the extension's details.

“Reload the page and try again”

The page lost contact with the extension, typically because the page reloaded itself or the extension was updated while the page was open. Reload the page and capture again.

“The tab changed during capture”

A full-page capture needs the tab to stay in front until it finishes. Start the capture again and stay on the tab.

The capture stops before the end of a very long page

PageReel captures up to 200 screens. Longer pages are cut off there, and the result page says so. Chrome also limits captures to two per second, which is why long pages take a while.

An ad still appears in my capture

Ad hiding recognizes common ad markup, so an unusual or custom-built ad can get through. You can cover it with the Blackout tool in the editor.

Part of the page is missing or repeated

Some pages load content only while you scroll, or move elements around as you go. Scroll to the bottom of the page yourself once, return to the top, and capture again. If it still looks wrong, use Select area for the part you need.

I closed the tab with my capture. Can I get it back?

Captures are kept for one day. Reopen the result tab from Chrome's history (Ctrl+H) within that time. After a day they are deleted.

Privacy

PageReel collects nothing. Captures stay in your browser. The details are in the privacy policy.

Contact

Still stuck, or found a page that will not capture properly? Use the support link on PageReel's Chrome Web Store listing. It helps to include the page's address and which mode you used.
